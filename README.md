**📊 Amazon Product Sales Analysis Dashboard**

Built an interactive Power BI dashboard to analyze Amazon product sales performance, customer reviews, and category-wise trends. This end-to-end analytics project transforms raw sales data into actionable business insights through data cleaning, modeling, visualization, and KPI tracking.

Key Highlights:

✅ Analyzed sales, quantity sold, and customer review metrics across multiple product categories
✅ Designed dynamic KPIs including YTD Sales, QTD Sales, Products Sold, and Customer Reviews
✅ Created interactive filters for category-level analysis and performance tracking
✅ Visualized monthly sales trends, weekly sales patterns, and top-performing products
✅ Identified high-revenue products and categories to support data-driven decision-making
✅ Developed a professional and user-friendly dashboard using Power BI best practices

Tools & Technologies:

🔹 Power BI
🔹 SQL
🔹 Excel / Data Cleaning
🔹 DAX Measures & Calculated Columns
🔹 Data Modeling & Visualization

This project demonstrates my ability to convert business requirements into meaningful dashboards and deliver insights that help stakeholders monitor performance and identify growth opportunities.
